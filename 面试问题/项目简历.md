# 短视频 Feed 流系统（Go 后端）

**技术栈**：Go 1.25 + Gin + GORM + MySQL 8.0 + Redis 7 + RabbitMQ + Docker + Vue 3  
**项目地址**：[GitHub](https://github.com/your-repo/feedsystem_video_go-main)  
**核心亮点**：API/Worker 进程分离架构 | 三级缓存加速 | 冷热分离 Feed 流 | 滑动窗口热榜 | 消息驱动异步架构

---

## 项目概述

独立设计并开发了一套高并发短视频 Feed 流系统，支持视频发布、点赞、评论、关注、Feed 流推送、热度排行等核心功能。**API 进程和 Worker 进程分离部署**，通过 RabbitMQ 异步解耦，支撑从原型到生产级的业务演进。

---

## 重点难点与面试引导

### 🎯 亮点一：缓存架构与 Feed 流性能优化
> **引导问题方向** → 详见 `面试问题/01-Feed流与缓存设计.md`

- 实现了 **L1 本地内存 (3s TTL) → L2 Redis 分布式缓存 (1h TTL) → L3 MySQL + SingleFlight 防击穿** 三级缓存链路
- 设计 **冷热分离 + 水印线机制**：Redis ZSET 只缓存最新 1000 条视频 ID，用户翻到旧数据自动降级 MySQL，99% 的请求走缓存
- 实现 **Redis ZUNIONSTORE 滑动窗口热度算法**：每分钟一个 ZSET，合并 60 个分钟窗口生成实时热榜
- **全接口游标分页**（Cursor Pagination），拒绝 LIMIT OFFSET，翻页性能不衰减；热门榜使用 **双字段游标 `(likes_count, id)`** 解决同分数据遗漏问题

### 🎯 亮点二：消息驱动与异步架构
> **引导问题方向** → 详见 `面试问题/02-消息队列与异步架构.md`

- 采用 **API/Worker 进程分离架构**，点赞、关注、评论等写操作异步化，用户响应时间从 900ms 降至 3ms
- 基于 **RabbitMQ Topic Exchange** 实现灵活的消息路由，每个业务独立 Exchange + Routing Key
- 设计 **Outbox（事务发件箱）模式**，保证视频发布时数据库写入与 MQ 消息发送的最终一致性
- Worker 进程实现 **优雅关闭**（signal.NotifyContext + 手动 ACK），重启时消息零丢失
- **MQ 宕机自动降级**：MQ nil 检测切换为同步写 DB，用户无感知

### 🎯 亮点三：安全防护体系
> **引导问题方向** → 详见 `面试问题/03-认证、限流与安全.md`

- **JWT 双层认证**：第一层 HS256 签名校验，第二层 DB/Redis Token 比对，支持主动踢下线
- **SoftJWTAuth 宽松模式**：Feed 流接口未登录也能刷，通过 `accountID = 0` 标识游客
- **基于 Redis INCR + PEXPIRE Lua 脚本的滑动窗口限流**，区分 IP 维度（登录）和用户维度（点赞/评论）
- **bcrypt 密码存储**：自动加盐 + 可调迭代次数（cost=10），拒绝 MD5/SHA256

### 🎯 亮点四：数据库与 SQL 优化
> **引导问题方向** → 详见 `面试问题/04-数据库与Go工程实践.md`

- **关注流查询使用子查询 IN 替代 JOIN**，避免大表笛卡尔积，查询耗时从百毫秒级降至毫秒级
- 关键业务操作使用 **GORM 事务**（评论发布 + 计数更新、改名 + Token 刷新），保证 ACID
- **Docker 多阶段构建**：CGO_ENABLED=0 + `-ldflags="-s -w"` + Alpine，镜像从 800MB 优化至 15MB
- 手动依赖注入，无 DI 框架依赖，编译期类型安全

### 🎯 亮点五：整体系统设计
> **引导问题方向** → 详见 `面试问题/05-系统设计与架构.md`

- Feed 流采用 **拉模式（读扩散）**，实现简单且适合中小规模；可平滑演进为推拉混合模式
- **所有 Redis 操作套上 50ms 超时 context**：Redis 宕机时自动降级 DB，系统不崩溃
- **SingleFlight 三重防护**：视频详情查询、冷数据降级、ZSET 自动重建均加 SingleFlight 防击穿
- **最终一致性 + 乐观更新**：点赞等操作先更新前端 UI，失败后回滚，用户体验丝滑

## 技术成长

通过这个项目深入掌握了 Go 语言的并发模型（goroutine + channel + context）、GORM 与 SQL 优化、Redis 高级数据结构（ZSET 排行榜 + 滑动窗口）、RabbitMQ 消息可靠投递、Docker 容器化部署等生产级技能，具备从单体到分布式架构演进的设计思维。
