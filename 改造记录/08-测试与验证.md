## 5. 手工验证步骤

### 5.1 准备环境

```bash
cp .env.example .env
# 修改 .env
docker compose up -d mysql redis rabbitmq
```

或本地启动 MySQL/Redis/RabbitMQ。

设置后端环境变量（PowerShell）：

```powershell
$env:CONFIG_PATH="configs/config.yaml"
$env:DB_HOST="localhost"
$env:DB_PORT="3306"
$env:DB_USER="root"
$env:DB_PASSWORD="123456"
$env:DB_NAME="feedsystem"
$env:REDIS_HOST="localhost"
$env:REDIS_PORT="6379"
$env:REDIS_PASSWORD=""
$env:JWT_SECRET="dev-secret-change-me"
cd backend
go run ./cmd
```

### 5.2 注册

```bash
curl -X POST http://localhost:8080/account/register \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"password"}'
```

期望：

```json
{"message":"account created"}
```

### 5.3 登录

```bash
curl -X POST http://localhost:8080/account/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"password"}'
```

期望：

```json
{
  "token": "<access_token>",
  "access_token": "<access_token>",
  "refresh_token": "<refresh_token>",
  "token_type": "Bearer",
  "expires_in": 900,
  "refresh_expires_in": 604800
}
```

### 5.4 调用受保护接口

```bash
curl -X POST http://localhost:8080/video/publish \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"title":"demo","play_url":"http://example.com/a.mp4","cover_url":"http://example.com/a.jpg"}'
```

期望：200，返回视频对象。

### 5.5 刷新 Token

```bash
curl -X POST http://localhost:8080/account/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"<refresh_token>"}'
```

期望：返回新的 `access_token` 和 `refresh_token`。

### 5.6 重放旧 Refresh Token

再次使用刷新前的旧 `refresh_token`：

期望：

```json
{"error":"token has been revoked"}
```

状态码 401。

### 5.7 登出

```bash
curl -X POST http://localhost:8080/account/logout \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"<refresh_token>"}'
```

期望：`account logged out`。

### 5.8 限流

连续快速请求登录接口：

```bash
for i in {1..15}; do
  curl -s -o /dev/null -w "%{http_code}\n" \
    -X POST http://localhost:8080/account/login \
    -H "Content-Type: application/json" \
    -d '{"username":"alice","password":"wrong"}'
done
```

期望：

- 前 10 次返回 401（密码错误）。
- 后续返回 429。

## 6. 数据库验证

登录后查询：

```sql
SELECT id, account_id, jti, family_id, expires_at, revoked_at
FROM refresh_tokens
ORDER BY id DESC
LIMIT 10;
```

刷新后：

- 旧记录 `revoked_at` 不为空。
- 新记录 `revoked_at` 为空。
- 两条记录 `family_id` 相同。

重放后：

- 同 Family 的所有记录 `revoked_at` 都不为空。

## 9. 测试设计原则

1. 应用层测试使用 fake，避免依赖数据库和 Redis。
2. JWT 测试使用真实实现，覆盖签名、类型、过期、篡改。
3. Redis Lua 测试使用 miniredis，验证令牌桶算法。
4. 表驱动测试优先，便于扩展场景。
5. 每个失败场景都要有明确错误断言，而不是只判断 `err != nil`。
